# Unemployment Analysis with Python

## Project Overview

This project was completed as part of the **Oasis Infobyte Data Science Internship**.

The objective of this project is to perform an exploratory data analysis (EDA) on unemployment data in India to identify regional and temporal trends, with special emphasis on understanding the impact of the COVID-19 pandemic on unemployment rates.

The project includes data preprocessing, statistical analysis, visualization, and interpretation of unemployment patterns across different Indian states and union territories. Various charts and graphical analyses are used to uncover meaningful insights that can support data-driven decision-making.

---

# Objective

The primary objectives of this project are:

- Analyze unemployment trends across different states of India.
- Study monthly unemployment patterns over time.
- Compare unemployment rates before and after the COVID-19 pandemic.
- Identify states with the highest average unemployment.
- Understand the relationship between unemployment rate, employment, and labour participation rate through correlation analysis.

---

# Dataset

The project uses the **Unemployment in India** dataset.

### Dataset Information

The dataset contains information such as:
