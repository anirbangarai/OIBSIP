# Projects Included

## Task 1 – Iris Flower Classification

### Objective

Develop a machine learning classification model to identify the species of an Iris flower based on its physical measurements.

### Highlights

- Exploratory Data Analysis (EDA)
- Pairplots and Boxplots
- Correlation Analysis
- Logistic Regression
- K-Nearest Neighbors
- Random Forest Classifier
- Model Evaluation
- Best Model Selection

---

## Task 2 – Unemployment Analysis with Python

### Objective

Analyze unemployment trends across India using exploratory data analysis and visualize the impact of the COVID-19 pandemic.

### Highlights

- Data Cleaning
- Time-Series Analysis
- State-wise Unemployment Analysis
- Correlation Heatmap
- COVID-19 Impact Analysis
- Statistical Interpretation

---

## Task 3 – Car Price Prediction

### Objective

Predict the selling price of used cars using machine learning regression techniques.

### Highlights

- Data Preprocessing
- Feature Engineering
- Exploratory Data Analysis
- Linear Regression
- Random Forest Regressor
- Feature Importance
- Price Prediction

## Task 4 – Email Spam Detection

### Objective

Develop a Natural Language Processing (NLP) model to classify emails as Spam or Ham.

### Highlights

- Text Cleaning
- TF-IDF Vectorization
- Naive Bayes
- Logistic Regression
- WordCloud Visualization
- Confusion Matrix
- Classification Report

## Task 5 – Sales Prediction using Machine Learning
